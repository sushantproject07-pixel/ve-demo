How to try it

  1. Click Open in editor on any card. Each time it opens, the editor asks how you want to work: Basic (text and duplicates), Smart (colours, links, images) or Developer (everything).
  2. Hover to see blocks, click to select, double-click any text to type over it.
  3. Use the toolbar to change colour, font, links, images and buttons. Duplicate or delete repeating items like speaker cards.
  4. Switch to the phone icon to edit the mobile view, then press Submit for approval to see the review sheet.
